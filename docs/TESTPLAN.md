# COBOL Accounting Application Test Plan

This plan describes the behavior implemented in `src/cobol/main.cob`,
`src/cobol/operations.cob`, and `src/cobol/data.cob`. It is intended for
business-stakeholder review and as a behavioral baseline for the Node.js
replacement.

## Execution notes

- Unless a case says otherwise, start a fresh application process. The initial
  account balance is `1000.00`; balance changes are held by the running
  application and are not written to external storage.
- Run interactive cases through the menu. Run the DataProgram and unknown
  operation cases as component-level tests using the program call interface.
- `Actual Result` and `Status (Pass/Fail)` are execution fields. Record the
  observed result and mark Pass or Fail only after stakeholder execution; all
  cases below are currently Not run for acceptance. Local compiler probes noted
  in Comments are characterization only, not stakeholder sign-off.
- The COBOL source does not define business rules for malformed numeric input,
  negative amounts, excess decimal precision, or arithmetic overflow. The
  related cases are characterization tests: record the compiler/runtime
  behavior and obtain stakeholder approval before treating an outcome as a
  requirement for the Node.js version.
